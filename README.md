# EzCore

EzCore is the official Unreal Engine 5 plugin for integrating games with the EZFest platform.

## Features

- User authentication
- REST API integration
- Online services
- Blueprint support
- C++ API
- Cross-platform compatibility

## Requirements

- Unreal Engine 5.4 or later

## Installation

1. Clone or download this repository.
2. Copy the `EzCore` folder into your project's `Plugins` directory.
3. Enable the plugin from the Unreal Engine Plugin Manager.
4. Restart the editor.
